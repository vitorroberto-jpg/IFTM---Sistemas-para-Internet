# IFTM - Sistemas para Internet

Este repositório será utilizado ao longo do curso de Tecnologia em Sistemas para Internet, servindo como um espaço para armazenar atividades, exercícios, projetos, anotações e materiais de estudo das disciplinas do 2º período.

O curso de Tecnologia em Sistemas para Internet tem como objetivo geral formar tecnólogos com conhecimentos teóricos e práticos, preparando-os para atuar com excelência na área de tecnologia da informação, com visão crítica, ética e cidadã, alinhada às demandas do arranjo produtivo da região.

## Contexto acadêmico
Este repositório acompanha a trajetória acadêmica no período atual, com foco nas disciplinas abaixo:

- Algoritmos
- Banco de Dados
- JavaScript Básico
- Programação Orientada a Objetos I
- Sistemas Web
