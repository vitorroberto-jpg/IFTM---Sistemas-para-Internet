---

## 📌 Sobre o Curso

O curso de Tecnologia em Sistemas para Internet forma profissionais focados no desenvolvimento de softwares web, móveis, arquitetura de sistemas, banco de dados e APIs, unindo sólida base teórica a práticas modernas do mercado.

* **Nível:** Graduação (Tecnólogo)
* **Modalidade:** Presencial
* **Carga Horária Total:** 2.727 horas
* **Página Oficial do Curso:** [IFTM - Sistemas para Internet](https://iftm.edu.br/cursos/uberlandiacentro/tecnologo/sistemas-para-internet/)

## 🚀 Principais Tecnologias & Competências Desenvolvidas

* **Front-end:** HTML5, CSS3, JavaScript ES6+, UX/UI Design.
* **Back-end & Arquitetura:** Programação Orientada a Objetos, Padrão MVC, Microsserviços, ORM, Testes Automatizados.
* **Banco de Dados:** SQL e NoSQL (Projetos, Modelagem e Administração).
* **Mobile & Distribuídos:** Aplicações Móveis Native/Cross-Platform e Sistemas Distribuídos.
* **Práticas Profissionais:** Engenharia de Requisitos, Segurança da Informação, Empreendedorismo.
